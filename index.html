Como mudar esta página

  1. Abra o index.html no GitHub e clique no lápis para editar os textos.
  2. Para trocar as cores, mude os valores no começo do style.css.
  3. Clique em Commit changes para salvar. Em um ou dois minutos a nova versão está no ar.
